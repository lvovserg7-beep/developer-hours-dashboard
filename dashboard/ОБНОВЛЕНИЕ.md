# Обновление боевого дашборда

Рабочая папка в Cursor и боевой сервер — **разные** копии. На боевую не копируют ZIP с рабочего стола. Берут стабильный тег с GitHub (файл `STABLE` в корне репозитория, сейчас смотрите [STABLE](../STABLE) или [релизы](https://github.com/lvovserg7-beep/developer-hours-dashboard/releases)).

Репозиторий **публичный**: для `git clone` / `git fetch` вход в GitHub обычно не нужен. Нужны Git, сеть до GitHub и папка-клон (есть скрытый каталог `.git`).

Секреты на машине остаются своими: `dashboard/.env` и `dashboard/users.json` скрипт обновления **не затирает**.

---

## Обычное обновление (уже есть git-клон)

### Windows

Типичный путь: `C:\Apps\developer-hours-dashboard`.

1. Дождитесь, пока в руководстве / `STABLE` появится новая версия (или возьмите тег с [страницы релизов](https://github.com/lvovserg7-beep/developer-hours-dashboard/releases)).
2. Запустите:

```text
C:\Apps\developer-hours-dashboard\dashboard\update-stable.cmd
```

Скрипт:

- прочитает тег из `STABLE` (или из аргумента, см. ниже);
- сделает `git fetch --tags` и `git checkout --force` на этот тег;
- перезапустит сервер через `start.cmd`.

Другой тег вручную:

```text
C:\Apps\developer-hours-dashboard\dashboard\update-stable.cmd v2.1.1
```

3. Проверка в браузере: `http://localhost:8787/` (или LAN-адрес машины).

### Linux

Типичный путь: `/opt/developer-hours-dashboard`.

```bash
/opt/developer-hours-dashboard/dashboard/update-stable.sh
```

Или явно: `./update-stable.sh v2.1.1`.

Если активен systemd-сервис `developer-hours-dashboard`, скрипт его перезапустит. Иначе после checkout снова запустите:

```bash
cd /opt/developer-hours-dashboard/dashboard
./start.sh
```

или: `sudo systemctl restart developer-hours-dashboard`.

## Первый раз: вместо ZIP сделать клон

Если папки `.git` нет, `update-stable` откажется работать. Один раз переведите установку на клон.

### Windows

1. Остановите окно `start.cmd`.
2. Скопируйте в сторону `dashboard\.env` и `dashboard\users.json` (если есть).
3. Переименуйте старую папку, например в `C:\Apps\developer-hours-dashboard.bak`.
4. Клон (подставьте актуальный тег из `STABLE`):

```powershell
cd C:\Apps
git clone --branch v2.1.1 https://github.com/lvovserg7-beep/developer-hours-dashboard.git
```

5. Верните `.env` и `users.json` в `C:\Apps\developer-hours-dashboard\dashboard\`.
6. Запустите `C:\Apps\developer-hours-dashboard\dashboard\start.cmd`.

Проверка, что это клон:

```powershell
cd C:\Apps\developer-hours-dashboard
dir .git
git status
```

### Linux

1. Остановите `./start.sh` или `sudo systemctl stop developer-hours-dashboard`.
2. Сохраните `dashboard/.env` и `dashboard/users.json`.
3. Переименуйте старую папку и клонируйте:

```bash
cd /opt
sudo mv developer-hours-dashboard developer-hours-dashboard.bak
sudo git clone --branch v2.1.1 https://github.com/lvovserg7-beep/developer-hours-dashboard.git
# верните .env и users.json в .../dashboard/
sudo chmod +x /opt/developer-hours-dashboard/dashboard/*.sh
```

4. Запуск: `./start.sh` или `sudo systemctl start developer-hours-dashboard`.

## Что не трогать при обновлении

| Файл | Зачем |
|------|--------|
| `dashboard/.env` | OData, Bitrix, маркетплейсы, админ |
| `dashboard/users.json` | логины дашборда |
| `dashboard/data/` | локальный кэш/снимки (при желании можно оставить) |

Их не коммитят и не кладут в ZIP с Cursor.

---

## Если Git недоступен

Только ZIP **со страницы релиза** на GitHub (Source code), не архив из Cursor. Распаковать поверх той же папки, **не затирая** `.env` и `users.json`. Дальше `update-stable` по-прежнему не заработает, пока не сделаете полноценный `git clone`.

---

## Частые проблемы

| Симптом | Что проверить |
|---------|----------------|
| «This folder is not a git clone» | Нет `.git` — см. раздел «вместо ZIP» |
| Ошибка `git fetch` | Сеть, DNS, доступ к github.com |
| После обновления 401 к 1С | Целы ли `.env`, правильные логин/пароль OData |
| Порт занят / старая версия в браузере | Закрыть старый `start.cmd`, жёсткое обновление страницы; на Linux — `systemctl status` |
| Нужна не та версия | `update-stable.cmd vX.Y.Z` / `./update-stable.sh vX.Y.Z` |

Текущий тег на диске после обновления:

```text
git -C C:\Apps\developer-hours-dashboard describe --tags
```

или на Linux:

```bash
git -C /opt/developer-hours-dashboard describe --tags
```
