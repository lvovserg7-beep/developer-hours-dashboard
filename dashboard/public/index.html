Часы в работе по статусам — реквизит «Часы». Часы в работе по разработчикам — реквизит «Часы разработки», не общие часы задачи. Выполненные по разработчикам: анализ = часы минус разработка и внедрение; разработка = часы разработки и внедрения. Выполненные по аналитикам: только реквизит «Часы внедрения», без часов анализа. Аналитик — реквизит «Руководитель проектов».
